# AudioToolsTester 需求文档

## 1. 项目愿景

AudioToolsTester 致力于成为**语音交互的核心枢纽**，让用户通过语音与计算机进行自然交互。从传统的文本输入转向语音输入，同时保持文字作为传输媒介，打造无缝的语音-文字-智能处理工作流。

---

## 2. 核心需求

### 2.1 AI优化提示词自定义 (P0 - 高优先级)

#### 背景
当前AI优化使用硬编码的单一提示词，无法适应不同场景需求：
- 程序员：需要更好的英文、代码术语处理
- 小说创作：需要保持人名一致性、文学风格
- 文案撰写：需要营销风格优化
- 会议记录：需要保留关键信息、提炼要点

#### 需求描述
用户可在设置页面管理AI优化提示词预设：

**功能点：**
1. **预设管理**
   - 系统内置预设：通用、程序员、小说、会议、文案
   - 用户可新增/编辑/删除自定义预设
   - 预设包含：名称、描述、提示词模板

2. **提示词编辑器**
   - 支持变量占位符 `{text}` 表示待优化文本
   - 提供预览功能，可测试提示词效果
   - 支持导入/导出预设（JSON格式）

3. **快速切换**
   - 录音界面提供预设快速选择下拉框
   - 记住上次使用的预设

**验收标准：**
- 用户可创建至少5个自定义预设
- 预设可按场景分类管理
- 切换预设后立即生效

---

### 2.2 多段录音模式 (P0 - 高优先级)

#### 背景
当前录音模式为"录完整段再上传"，存在以下问题：
- 无法实时看到转写结果
- 长时间录音需等待较长时间
- 无法在录音过程中获得反馈

#### 需求描述
新增"多段录音"模式，支持实时流式转写：

**功能点：**
1. **静音检测分割**
   - 可配置静音阈值（默认1.5秒）
   - 静音持续达到阈值自动分割音频
   - 分割后的片段自动上传转写

2. **流式转写展示**
   - 转写结果实时显示在界面
   - 新片段结果追加到现有文本后
   - 支持实时编辑已转写文本

3. **录音控制**
   - 支持暂停/恢复录音
   - 支持手动分割（点击按钮强制分割）
   - 录音结束后自动合并所有片段为一个记录

4. **模式切换**
   - 设置页面提供录音模式选择
   - 单段录音 / 多段录音 两种模式

**验收标准：**
- 静音检测准确率 > 90%
- 片段转写延迟 < 3秒
- 支持长达30分钟的连续录音

---

### 2.3 WebSocket状态通知 (P1 - 中优先级)

#### 背景
当前转录状态通过轮询 `/api/records/{id}/status` 获取，效率较低：
- 每2秒发起一次HTTP请求
- 服务端需处理大量无效轮询
- 用户体验不如实时推送

#### 需求描述
将状态轮询改为WebSocket推送通知：

**功能点：**
1. **状态推送**
   - 转录开始/进度/完成通知
   - AI优化开始/完成通知
   - 错误状态通知

2. **进度展示**
   - 转录进度百分比（如适用）
   - 预估剩余时间
   - 处理状态实时更新

3. **兼容性**
   - WebSocket断开时自动降级为轮询
   - 重连后同步最新状态

**验收标准：**
- 状态更新延迟 < 500ms
- 断线重连成功率 100%
- 轮询降级平滑无感知

---

### 2.4 多LLM服务商支持 (P1 - 中优先级)

#### 背景
当前DeepSeek API密钥硬编码在 `.env` 文件中，用户无法：
- 切换其他LLM服务商
- 配置多个API密钥
- 灵活选择模型

#### 需求描述
设置页面支持配置多个LLM服务商：

**功能点：**
1. **服务商配置**
   - 支持的服务商：DeepSeek、Claude、OpenAI、豆包、通义千问
   - 每个服务商配置：API密钥、模型选择、温度等参数
   - API密钥加密存储

2. **快速切换**
   - 下拉框选择当前使用的服务商
   - 切换后立即生效

3. **自定义端点**
   - 支持自定义API端点（用于代理或私有部署）
   - 支持自定义请求头配置

**验收标准：**
- 至少支持5个主流LLM服务商
- API密钥本地加密存储
- 服务商切换无重启生效

---

### 2.5 Electron桌面应用 (P2 - 中低优先级)

#### 背景
当前PySide6托盘工具存在局限：
- 功能单一，仅支持热键录音
- 跨平台体验不一致
- UI扩展性受限

#### 需求描述
开发Electron桌面应用替代PySide6托盘：

**功能点：**
1. **系统托盘**
   - 托盘图标状态显示（空闲/录音/转写中/离线）
   - 右键菜单：快速操作、历史记录、设置、退出
   - 点击托盘：显示主窗口

2. **主窗口**
   - 完整的Web界面功能（内嵌Chromium）
   - 历史录音列表
   - 快速搜索和筛选

3. **全局热键**
   - 按住录音模式（与当前行为一致）
   - 热键可自定义

4. **增强功能**
   - **滑词翻译**：选中文本自动弹出翻译结果
   - **剪切板集成**：录音文本自动复制到剪切板
   - **快捷分享**：一键分享到常用应用

5. **跨平台**
   - macOS、Windows、Linux 支持
   - 自动更新机制

**验收标准：**
- 功能覆盖现有PySide6托盘
- 支持macOS和Windows
- 安装包体积 < 150MB

---

### 2.6 移动端应用 (P2 - 中低优先级)

#### 背景
移动场景下的录音需求：
- 会议记录、采访、灵感捕捉
- 移动端录音质量通常更好（专用麦克风）
- 便于随时随地使用

#### 需求描述
开发移动端应用，连接主机端服务：

**功能点：**
1. **连接方式**
   - 扫描二维码连接（推荐）
   - 输入链接+密钥连接
   - 仅输入密钥连接（局域网自动发现）

2. **核心功能**
   - 录音并上传到主机端处理
   - 查看历史录音和转写结果
   - 推送录音文本到主机剪切板

3. **音频传输**
   - 实时流式上传
   - 支持选择本地音频文件上传
   - 断点续传支持

4. **离线模式**
   - 本地缓存未上传录音
   - 网络恢复后自动同步

**验收标准：**
- 支持iOS和Android
- 局域网连接延迟 < 100ms
- 支持后台录音

## 3. 扩展需求

### 3.1 语音交互场景扩展

基于"语音是未来交互方式"的理念，探索以下场景：

| 场景 | 描述 | 核心价值 |
|------|------|----------|
| **语音备忘录** | 快速记录想法、待办事项 | 解放双手，快速捕捉灵感 |
| **语音日记** | 口述日记，自动转写保存 | 自然表达，记录生活 |
| **语音邮件** | 语音输入，AI生成正式邮件 | 提高沟通效率 |
| **语音编程** | 语音输入代码注释、文档 | 程序员友好 |
| **语音翻译** | 实时语音翻译 | 跨语言沟通 |
| **语音搜索** | 语音提问，AI回答 | 知识获取 |
| **语音控制** | 语音控制应用操作 | 无障碍访问 |
| **会议助手** | 实时记录会议内容，提取要点 | 团队协作 |

### 3.2 协作功能

1. **多端同步**
   - 录音记录云端同步
   - 多设备无缝切换

2. **团队协作**
   - 共享录音记录
   - 协作编辑转写文本
   - 评论和标注

3. **集成能力**
   - 导出到Notion、Obsidian
   - 集成到工作流工具（Zapier等）

### 3.3 智能功能

1. **语音命令**
   - "标记重点"、"删除上一句" 等语音命令
   - 录音过程中交互式编辑

2. **智能摘要**
   - 自动提取关键信息
   - 生成会议纪要

3. **情感分析**
   - 分析说话人情绪
   - 标记重要片段

---

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 录音响应延迟 | < 100ms |
| 转写启动延迟 | < 2s |
| WebSocket消息延迟 | < 500ms |
| 移动端连接时间 | < 3s |
| 内存占用 | < 500MB |

### 4.2 安全要求

1. API密钥本地加密存储
2. 通信支持HTTPS/WSS加密
3. 用户数据本地优先，可选云端备份
4. 访问密钥定期轮换机制

### 4.3 兼容性要求

1. **桌面端**：macOS 10.15+、Windows 10+
2. **移动端**：iOS 14+、Android 10+
3. **浏览器**：Chrome、Safari、Firefox 最新两个大版本
4. **服务端**：Python 3.10+、Node.js 18+

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
