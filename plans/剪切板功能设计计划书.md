# 剪切板功能设计计划书

## 一、背景与目标

### 1.1 项目背景
当前 Audio-to-Text 应用已具备语音录制、转写、AI优化等核心功能。为进一步提升用户体验，增加**剪切板历史管理**功能，实现跨平台剪切板内容的自动同步、分类管理和快速操作。

### 1.2 设计目标
- 提供专业的剪切板历史管理界面
- 支持多种内容类型（文本、图像、链接、文件路径）
- 实现快速搜索、筛选、收藏等操作
- 与现有系统托盘工具深度集成

---

## 二、设计理念

**主题：Digital Obsidian（数字黑曜石）**

设计灵感来源于专业音频工程设备和技术转录套件，追求高端、单体的硬件质感。

- **色调**：深邃黑色基底 + 琥珀金色强调
- **原则**：无实线边框、色调分层、玻璃质感
- **风格**：专业、高端、沉浸式

## 五、样式规范

### 5.1 颜色系统
| 令牌名 | 色值 | 用途 |
|--------|------|------|
| background | `#131313` | 基础背景 |
| primary | `#ffc557` | 金色强调 |
| primary-container | `#e8a70f` | 次级强调 |
| surface-container-low | `#1c1b1b` | 侧边栏背景 |
| surface-container-high | `#2a2a2a` | 卡片背景 |
| surface-container-highest | `#353534` | 按钮背景 |
| surface-container-lowest | `#0e0e0e` | 输入框背景 |
| on-surface | `#e5e2e1` | 主要文字 |
| on-surface-variant | `#d0c5af` | 次要文字 |
| outline-variant | `#4d4635` | 边框线 |
| error | `#ffb4ab` | 错误状态 |

### 5.2 字体
- **标题**：Manrope
- **正文**：Inter / PingFang SC

### 5.3 圆角
- 默认：`0.125rem`
- 大圆角：`0.25rem`
- 超大圆角：`0.5rem`

### 5.4 设计原则
1. **No-Line 规则**：禁止使用 1px 实线边框，通过背景色差异区分区域
2. **Glass & Gradient**：浮动元素使用半透明背景 + backdrop-blur
3. **Tonal Layering**：深度通过色调分层实现

## 六、交互设计

### 6.1 悬停效果
- 卡片：背景色变亮 + 显示操作按钮
- 图像：灰度 → 彩色，透明度 60% → 100%
- 按钮：背景色变化 + 光标变化

### 6.2 状态反馈
- 当前导航：左侧 4px 金色边框 + 金色文字
- 收藏状态：填充金色星标
- 激活页码：金色背景按钮

### 6.3 过渡动画
- 统一使用 `transition-all duration-300 ease-in-out`
- 图片变换使用 500-700ms

## 八、技术实现要点

### 8.1 前端实现
- 基于现有 `static/` 目录结构扩展
- 新增剪切板相关 JS 模块
- 复用现有 WebSocket 实时通信机制

### 8.2 后端实现
- 新增剪切板数据模型（`app/clipboard/models.py`）
- 新增剪切板管理器（`app/clipboard/manager.py`）
- 新增 API 路由（`app/clipboard/routes.py`）
- 支持本地加密存储

### 8.3 系统托盘集成
- 扩展托盘工具支持剪切板监听
- 支持全局快捷键唤起悬浮窗口
- 与现有热键系统协同工作
