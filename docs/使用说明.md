# Audio to Text 使用说明

> 本文只描述**代码里真实存在**的行为。凡界面上找不到入口、或改了没有效果的功能，都在文中明确标注。

---

## 1. 这是什么

Audio to Text（ATT）是一个 Windows / macOS / Linux 桌面应用：**按下热键说话 → 自动转写成文字 →（可选）AI 优化 → 自动复制到剪贴板**。它由三部分组成：Electron 主进程（托盘、热键、剪贴板监控、窗口）、Vue 3 渲染界面（`src/`）、本地 FastAPI 后端（`app/`）。

界面左侧只有五个页面（`src/components/layout/Sidebar.vue:13-70`）：

1. **首页**：录音 + 实时转录 + 历史记录（`src/App.vue:23-26`）
2. **记录集**：搜索、筛选、编辑历史转写（`src/App.vue:28-30`）
3. **剪切板**：剪贴板历史（`src/App.vue:32-34`）
4. **生词本**：划词翻译沉淀的单词/短语/句子（`src/App.vue:36-38`）
5. **设置**：全部配置（`src/App.vue:40-42`）

主要能力（每项都能在代码里找到）：

- 三种录音模式：单段 / 多段（静音自动切段）/ 流式（`src/composables/useRecorder.js:1412-1422`）
- 三种 ASR：Whisper（本地）、Qwen3-ASR（本地）、豆包语音（火山引擎在线）（`src/components/settings/SettingsPage.vue:14-18`）
- LLM 文本优化，提示词预设来自 `prompts/*.txt`（`src/components/settings/SettingsPage.vue:271-287`）
- 自动复制到剪贴板并尝试粘贴到当前焦点输入框（`src/composables/useRecorder.js:413-433`）
- 记录集：搜索 / 收藏 / 编辑 / 音频回放 / 分页
- 剪贴板历史：自动采集文本与图片，支持收藏、置顶、搜索
- 生词本：单词 / 短语 / 句子条目与收藏（**条目当前无产生入口，见 §7**）
- Agent 对话：设置页内多轮问答，走「默认 LLM 配置」（`src/components/settings/AgentChatPanel.vue`）
- 系统托盘菜单、全局热键、录音浮窗、录音时自动静音系统输出

## 2. 启动与首次配置

### 2.1 启动方式

1. **开发模式（推荐）**：在仓库根目录执行 `npm run electron:dev`。它会同时启动 Vite（固定 8090 端口）和 Electron，Electron 自己拉起 Python 后端（`package.json:13`、`vite.config.js:33-34`）。
2. **复用已启动的后端**：`npm run electron:dev:existing-backend`，需要后端已经在运行（`package.json:14`）。
3. **只跑后端**：`npm run backend:dev:uv`，即 uvicorn --reload，默认 8000 端口（`package.json:12`）。
4. **Docker 一键脚本**（Windows）：`att-start.bat` 启动容器、`att-start-app.bat` 启动容器并打开桌面应用、`att-status.bat` 看状态、`att-stop.bat` 停止、`att-logs.bat` 看日志。这些脚本内部调用 `scripts/docker/att.ps1`，桌面应用通过 `ATT_BACKEND_PORT`（默认 8000）复用容器后端。
5. **打包版**：`npm run electron:build:win` 产出在 `release/`。注意：项目自身记录 `--win` 在 nsis 阶段会失败，`release/` 里只有 `win-unpacked`（`AGENTS.md` §5）——这一点本轮未复现，**待确认**。

后端端口：默认 8000，若被占用会从 8000 起向后找可用端口（最多 100 个）（`electron/python/manager.js:86,207-214`）。

### 2.2 首次需要配置什么

1. 打开「设置 → 语音识别」，选择 **ASR Provider**。默认是 `whisper`（`src/stores/settings.js:110`），首次使用会下载模型。
2. 回到「首页」，点右上角的 **开启模型**。按钮状态与文案见 `src/components/home/RecorderSection.vue:151-173`。
3. 打开「设置 → LLM 配置」，点 **管理配置 → 新建配置**，填 API Key 并设为默认（否则「自动 AI 优化」和 Agent 对话都会失败）。
4. 第一次点录音按钮时，系统会弹麦克风授权。设置页的「麦克风设备」下拉也是先请求一次权限再枚举设备（`src/components/settings/SettingsPage.vue:697-705`）。

## 3. 录音：三种模式

模式在「设置 → 录音设置 → 录音模式」切换（`src/components/settings/SettingsPage.vue:190-202`）。

### 3.1 单段录音 `single`（默认）

- 怎么用：按下录音按钮或热键开始，再按一次（或松开热键）结束。
- 结束后的流程：整段音频上传 → 后端转写 → 轮询状态 → 完成（`src/composables/useRecorder.js:1268-1316, 884-936`）。
- 限制：**时长不足 1 秒会被丢弃**，提示「录音时间过短」（`src/composables/useRecorder.js:890-896`、`869-882`）。
- 适合：一次说一小段、需要完整音频再统一转写的场景。

### 3.2 多段录音 `multi`

- 怎么用：按下开始后持续说话，**说完一句停顿片刻**，系统按静音自动切段并实时追加文本（`src/components/home/RecorderSection.vue:230-234`）。
- 实现：先创建会话 → 静音检测器按 `silence_threshold` 切段 → 每段单独上传 → 结束时合并成一个记录（`src/composables/useRecorder.js:1318-1394, 976-1056`）。
- 静音分段阈值：默认 1.5 秒，界面范围 0.5–5 秒（`src/components/settings/SettingsPage.vue:217-223`）；实际下限被夹到 400ms（`src/composables/useRecorder.js:1358`）。
- 超长语句会被强制拆段，状态提示「当前语句较长，正在拆分为较大的片段」（`src/composables/useRecorder.js:1127`）。
- 适合：边说边看文字、会议记录式的连续输入。

### 3.3 流式录音 `streaming`（真流式）

- 怎么用：按下开始后音频以 16kHz PCM 通过 WebSocket 持续发送，界面实时刷新文本（`src/composables/useRecorder.js:844-867, 1157-1213`）。
- **关键事实**：真流式只支持 `qwen_asr` 与 `doubao_asr` 两个 provider（`src/composables/recorder/streamProtocol.mjs:45`，校验见 `src/composables/useRecorder.js:1172-1174`）。选 `whisper` 时无法进入流式。
- **Qwen 流式在 Windows 上不可用**：后端在 Windows 直接判定不支持，提示「Windows 本地后端当前不支持流式服务，请切换为单段或多段录音。」（`app/stt/providers/qwen_asr_provider.py:115-124`）。需要配置远端桥接服务（`streaming_backend=remote_bridge` + 地址），本地可用 `npm run qwen:streaming:uv` 在 9000 端口起桥接（`package.json:15`、`app/services/streaming_bridge_target.py:64-72`）。
- **豆包流式是在线服务**，不需要「开启模型」，配好 Access Token 即就绪（`app/stt/providers/doubao_asr_provider.py:684-706`）。
- 界面上的「流式运行时状态」徽章就是后端 `qwen_streaming_available` 的直接反映（`src/components/settings/SettingsPage.vue:204-215, 476-492`）。
- 流式过程中连接意外断开，会停麦克风、停计时并提示「流式连接已断开，请重新开始录音」（`src/composables/useRecorder.js:226-246`）。

## 4. 热键与桌面行为

### 4.1 默认热键

| 平台 | 默认热键 |
| --- | --- |
| Windows | `Win+Alt` |
| macOS | `Cmd+Shift+R`（界面显示 ⌘⇧R） |
| Linux | `Ctrl+Shift+R` |

来源：`src/stores/settings.js:16-40`、`electron/desktop/settings.js:20-45`、`electron/python/desktop_agent.py:72-89`。

### 4.2 语义

1. **按下**开始录音，**松开**结束——即「长按说话」。热键由独立的 Python 桌面代理用 pynput 全局监听，通过 stdio JSON-RPC 与 Electron 通信（`electron/python/desktop_agent.py:193-301`）。
2. 按下有 250ms 防抖，避免重复触发（`electron/python/desktop_agent.py:55, 287-301`）。
3. **太短的按下会被丢弃**：松开过快会走「录音时间过短」分支（`src/composables/useRecorder.js:869-882`）。
4. macOS 上监听热键需要「辅助功能」权限，缺失时会提示「桌面热键监听需要系统辅助功能权限」（`electron/python/desktop_agent.py:216-225`）。
5. 自定义热键：「设置 → 录音设置 → 录音快捷键」，点击输入框后直接按组合键。规则是**至少两个修饰键，或一个修饰键 + 一个字母/数字**（`src/components/settings/SettingsPage.vue:736-767`）；右侧按钮可恢复默认。

### 4.3 录音时暂停其他音频

开关「录音时暂停其他音频」默认**开启**（`src/stores/settings.js:129`）。它通过桌面代理调用系统静音接口：录音开始时静音、结束时恢复原状态（`electron/python/desktop_agent.py:126-190`）。若静音失败，录音会中止并提示「静音失败」（`src/composables/useRecorder.js:538-554`）。

### 4.4 托盘菜单

右键托盘图标只有三类菜单项（`electron/tray/index.js:134-177`）：

1. **最近 10 条记录**（时间倒序，显示「时间 - 文本前 40 字」），点击 = 复制该文本并粘贴到当前焦点窗口（`electron/tray/index.js:139-153`、`182-186`）
2. **设置**（打开主窗口并跳到设置页）
3. **退出**

单击/双击托盘图标 = 显示并聚焦主窗口（`electron/tray/index.js:110-129`）。图标与提示文字随状态变化：就绪 / 录音中 / 转写中 / 未连接（`electron/tray/index.js:217-233`）。

### 4.5 录音浮窗

录音期间会显示一个 512×40 的置顶小窗（屏幕底部居中，不可移动、不占任务栏），显示阶段、时长与实时文本（`electron/floatingWindow/index.js:5-7, 30-60`）。

## 5. 录音结果

1. **状态流转**：`transcribing`（转写中）→ `transcribed`（已转写）→ `optimizing`（优化中）→ `optimized`（已优化）；失败为 `failed`（`app/records/models.py:11-18`）。
2. **自动 AI 优化**：开关默认**关闭**；开启后转写完成会自动调用默认 LLM 优化（`src/components/settings/SettingsPage.vue:249-258`、`src/composables/useRecorder.js:1622-1636`）。
3. **自动复制到剪贴板**：开关默认**开启**；完成时会复制文本，并**尝试粘贴到当前焦点输入框**（`src/composables/useRecorder.js:413-433`；粘贴由 `electron/python/paste_helper.py` 执行，`electron/main.js:350`）。
4. **记录集**（左侧「记录集」页）：
   - 搜索：全部文本 / 仅原始文本 / 仅优化文本（`src/components/records/RecordsLibraryPage.vue:16-27`）
   - 筛选收藏；每页 100 条，支持上一页/下一页（`RecordsLibraryPage.vue:59-77, 109`；后端 `page_size` 上限 200，`app/api/routers/records.py:182`）
   - 点击卡片打开编辑弹窗：原始文本只读、优化文本只读，**「编辑内容」保存后写入 `optimized_text`（若已有优化文本）或 `raw_text`，并标记 `is_modified`**（`src/components/modals/RecordEditModal.vue:4-24, 64-71`）
   - 收藏、复制按钮（`RecordsLibraryPage.vue:153-185`）
5. **首页历史记录**：「选择模式」可多选并**批量删除记录及其音频文件**，删除前有二次确认（`src/components/home/RecordsSection.vue:39-63`）。
6. **音频回放**：每条记录卡片左侧有播放/暂停按钮，播放时会自动停掉上一条（`src/components/home/RecordCard.vue:17-37`、`src/composables/useRecords.js:123-163`）。
7. **导出**：后端有导出接口 `GET /api/records/{id}/export?format=txt|json`（`app/api/routers/records.py:381-415`），前端也有 `exportRecord` 封装（`src/composables/useRecords.js:84-101`），但**界面上没有任何导出按钮**——`useRecords()` 的调用方没有解构 `exportRecord`（`src/components/home/RecordsSection.vue:78-92`）。**目前导出功能没有入口。**

## 6. 剪贴板历史

### 6.1 条目怎么产生

Electron 每 **800ms** 轮询一次系统剪贴板（`electron/clipboardMonitor/index.js:8, 71-78`）：

1. 优先检查 `image/png`：有图片就按 PNG 内容的 SHA-256 判重，保存到 `data/clipboard/images/` 并提交后端（`electron/clipboardMonitor/index.js:95-115, 182-240`）。
2. 否则读取文本，与上次观察值比对，变化才提交（`electron/clipboardMonitor/index.js:118-149`）。
3. **应用自身写入会被跳过**（复制、自动复制等），通过 5 秒 TTL 的内部写入标记实现（`electron/clipboardMonitor/index.js:9, 35-66`）。
4. 后端不可用（拿不到端口）时会跳过采集并记日志（`electron/clipboardMonitor/index.js:144-146`）。

条目类型由内容自动判定：链接 / Windows 路径 / 长文本或代码（>280 字符、≥3 个换行，或含代码关键字）/ 普通文本（`app/clipboard/manager.py:75-95`）。重复复制同一内容**不会新建条目**，只更新时间和 `duplicate_count`（`app/clipboard/manager.py:242-270`）。

### 6.2 页面功能

- 搜索框（输入后 250ms 防抖刷新）、刷新按钮（`src/components/clipboard/ClipboardPage.vue:18-37, 275-279`）
- 快捷筛选：今天 / 收藏 / 置顶 / 纯文本 / 图片 / 文件 / 链接（`ClipboardPage.vue:39-74`、`src/utils/clipboardPresentation.js:12-18`）
- 单次最多取 120 条（`ClipboardPage.vue:168`）
- 卡片动作：**复制、删除（二次确认）、收藏、置顶**（`src/components/clipboard/ClipboardCard.vue:7-40, 72-78`）
- 图片条目：鼠标悬停时按需拉取图片并转成 DataURL 显示缩略图（`ClipboardCard.vue:59-70, 184-212`）

### 6.3 「统一浮层」当前打不开（重要）

`dist/` 里确实构建了 `unified-overlay.html`（`vite.config.js:20-23`），但**桌面版没有任何入口**：

1. 托盘菜单没有浮层项（`electron/tray/index.js:134-177`）。
2. 全仓库没有任何 `globalShortcut` 注册。
3. IPC 通道 `overlay:open-clipboard` / `overlay:open-selection` 只有 Electron 主进程的接收端（`electron/main.js:540-552`），渲染侧的调用封装（`src/composables/useElectron.js:118-134`）**没有任何组件调用**。
4. `src/App.vue:104-135` 仍保留处理 WebSocket 消息 `clipboard_overlay_command` 的逻辑，但：Electron 运行时直接忽略该消息（`src/App.vue:108-113`），且**后端已经不再下发这个消息类型**（全仓仅 `src/App.vue` 出现过该字符串）。

结论：「设置 → 剪切板悬浮窗」下的 4 个选项（重复触发行为 / 回车行为 / 打开时聚焦搜索框 / 点击复制后关闭悬浮窗）**改了不会有任何可见效果**。相关面板的代码是活的（`src/components/overlay/ClipboardPanel.vue`、`SelectionPanel.vue`），只是进不去。

## 7. 生词本

- 页面功能：搜索（单词/短语/释义/上下文）、类型筛选（全部/单词/短语/句子）、仅看收藏、收藏切换、统计（今日新增 / 累计词条 / 收藏词条 / 总查询次数）（`src/components/wordbook/WordbookPage.vue:15-50, 127-132`）。
- 条目字段：`normalized_text`、`translation`、`explanations`、`examples`、`language`、`entry_type`、`source_app`、`source_context`、`query_count`、`is_favorite`（`app/wordbook/models.py:22-39`）。
- 重复查询同一内容不会新建条目，而是 `query_count + 1`（`app/wordbook/manager.py:144-198`）。
- **条目来源只有一个**：AI「翻译」动作执行成功后自动写入生词本（`app/ai_actions/service.py:206-220`，仅 `TRANSLATE` 且 `auto_add_to_wordbook` 为真）。
- **而这个动作的界面只存在于统一浮层的「翻译」标签页**（`src/components/overlay/SelectionPanel.vue:126-131`，动作键只有 `translate`）。由于浮层没有入口（见 §6.3），**生词本页面目前无法产生新条目**。页面空态文案自己也写着「等划词动作中心接入后，这里会自动沉淀…」（`src/components/wordbook/WordbookPage.vue:62`）。
- **复习相关功能：代码里不存在**。没有复习计划、记忆曲线、掌握度、复习提醒等任何字段或页面；`query_count` 只是累计查询次数。

## 8. AI 动作与 Agent 对话

### 8.1 后端支持的动作

`translate` / `explain` / `summarize` / `rewrite` / `chat`（`app/ai_actions/routes.py:75-120`、`app/ai_actions/models.py:8-15`）。

**界面入口情况**：

| 动作 | 界面入口 |
| --- | --- |
| 翻译 translate | 只有统一浮层「翻译」页（**无入口**） |
| 解释 / 总结 / 改写 | **没有任何界面调用**（只有 `src/api/client.js:254-257` 的封装） |
| 对话 chat | ✅ 设置 → Agent 对话 |

### 8.2 走哪个 LLM 配置

全部走「设置 → LLM 配置 → 默认 LLM 配置」选中的那条（`app/ai_actions/service.py:99-103`）。可选服务商：DeepSeek / Claude (Anthropic) / OpenAI / 豆包（字节跳动）/ 通义千问（阿里云）/ 自定义（OpenAI 兼容）（`app/llm/models.py:66-102`）。每条配置含名称、API Key、API Base、模型、temperature、max_tokens；**API Key 加密落盘**（`data/llm_configs.json` 的 `api_key_encrypted`），编辑时留空表示保持原密钥（`src/components/modals/LLMEditModal.vue:14-44, 120-127`）。

> 「测试连接」后端接口存在（`POST /api/llm/configs/{id}/test`，`src/api/client.js:294`），但**界面上没有测试按钮**。

### 8.3 Agent 对话

- 位置：设置页「Agent 对话」分组（`src/components/settings/SettingsPage.vue:384-397`）。
- 交互：Enter 发送、Shift+Enter 换行；中文输入法组合期间的 Enter 不会误发送；有「清空会话」按钮（`src/components/settings/AgentChatPanel.vue:31-59, 89-99`）。
- **会话只存在内存里，不持久化**，刷新页面即重新开始（`AgentChatPanel.vue:77`）。
- 多轮历史会被拼成一条带角色前缀的 prompt 发给模型（`app/ai_actions/service.py:144-150`）。

### 8.4 失败时用户看到什么

- 未配置 LLM：后端返回 502，提示「未配置可用的 LLM 模型：请先到「设置 → LLM 配置」新增一条配置，填写 API Key 并设为默认后再试。」（`app/ai_actions/routes.py:19-22`），前端以 Toast 展示（`AgentChatPanel.vue:132-134`）。
- 模型返回非 JSON：回退把整段输出当作 `answer`（`app/ai_actions/service.py:105-114`）。
- 模型返回空内容：提示「Agent 没有返回内容，请稍后重试」（`AgentChatPanel.vue:127-129`）。
- AI 动作服务未初始化：503「AI 动作服务尚未初始化，请稍后重试」（`app/ai_actions/routes.py:58-62`）。

## 10. 常见问题（FAQ）

**Q1. 提示「无法访问麦克风，请检查系统权限或输入设备」怎么办？**
去系统设置里给应用开放麦克风权限，然后在「设置 → 录音设置 → 麦克风设备」重新选设备（该下拉会先请求一次权限再枚举，`src/components/settings/SettingsPage.vue:697-705`）。权限被拒时列表会是空的。

**Q2. 录音按钮是灰的 / 提示「请先开启模型」？**
本地 provider（Whisper / Qwen）需要先在首页点「开启模型」。模型加载中按钮显示「模型加载中」（`src/components/home/RecorderSection.vue:154-166`）。豆包是在线 provider，不需要开启模型，缺的是 Access Token——按钮会显示「请先配置 ASR 密钥」（`RecorderSection.vue:146-150, 162`）。

**Q3. 切到流式模式却提示不支持？**
三个可能：① 当前 provider 不是 `qwen_asr` / `doubao_asr`；② 后端跑在 Windows 且用本地 Qwen 流式（提示「Windows 本地后端当前不支持流式服务，请切换为单段或多段录音。」）；③ 流式服务还没起来（提示「流式模型服务尚未启动」）。设置页的「流式运行时状态」会显示具体原因（`src/components/settings/SettingsPage.vue:476-492`）。

**Q4. 豆包 Access Token 怎么配？**
1. 在火山语音技术控制台拿到 Access Token（**注意与方舟大模型 key 不通用**，`SettingsPage.vue:131`）。
2. 「设置 → 语音识别 → ASR Provider」选豆包语音。
3. 在「Access Token」输入框粘贴并保存。保存后后端立即用 Fernet 加密写入 `data/settings.json` 的 `doubao_asr_api_key_encrypted`，密钥文件是 `data/.encryption_key`；`GET /api/settings` 只返回 `doubao_asr_api_key_set` 布尔值，**不回传明文**（`app/services/settings_service.py:55-58, 151-153`、`app/utils/encryption.py:17-30`）。
4. Resource ID 必须与账号实际开通的产品一致：**ASR 1.0 用 `volc.bigasr.sauc.*`，2.0 用 `volc.seedasr.sauc.*`**。401 表示 Token 无效或过期，403 表示 Resource ID 与开通产品不匹配（`app/stt/providers/volcengine_sauc.py:676-700`）。
5. 想清空：打开「清除已保存的 Token」再等自动保存。

**Q5. 后端端口被占用？**
默认 8000。Electron 启动后端时会从 8000 起向后找一个可用端口（最多尝试 100 个）（`electron/python/manager.js:86, 207-214`）。也可以显式指定：环境变量 `ATT_BACKEND_PORT` 或 `PORT`。另外 Vite 固定 8090 且 `strictPort: true`，8090 被占用时前端会直接报错（`vite.config.js:33-34`）。

**Q6. 提示「另一个后端进程正在写」/ `data/.writer.lock`？**
完整提示是「检测到另一个 ATT 后端进程正在写同一份数据目录，已拒绝启动：… JSON 文件存储不支持多进程同时写入（会静默丢数据），请先关闭另一个后端进程…」（`app/repositories/writer_lock.py:368-374`）。处理办法：

1. 关掉另一个后端进程或 Docker 容器，再重启。
2. 锁文件带 15 秒心跳、60 秒判陈旧，正常退出会释放；确认没有别的进程后，也可以直接删掉过期的 `data/.writer.lock`。
3. 仅调试/迁移时可临时设 `ATT_ALLOW_MULTI_WRITER=1` 跳过该约束，**有丢数据风险**（`app/repositories/writer_lock.py:39-45`）。

**Q7. 日志在哪？**
- 后端日志：`logs/app.log`（JSON 行格式，5MB 滚动，带备份；`app/utils/logging.py:40-90`）
- Electron / 浮层 / 剪贴板监控日志：`logs/electron-overlay.log`（`electron/logger.js:4-5`）
- Qwen 流式桥接服务日志：`logs/qwen_streaming_service.log`
- 快速查看：Windows 下双击 `att-logs.bat`。

## 11. 已知限制（集中列出）

1. **统一浮层（剪贴板面板 / 划词面板）没有入口**：托盘无菜单项、无全局快捷键、IPC 通道没有渲染侧调用方、后端不再下发 `clipboard_overlay_command`。相关 4 个设置项改了没有效果（详见 §6.3）。
2. **生词本无法产生新条目**：唯一写入路径是统一浮层的「翻译」动作，而浮层打不开；生词本也**没有任何复习功能**（详见 §7）。
3. **提示词预设只能改文件**：`prompts/*.txt` 是唯一真相源，`/api/prompts` 的增/改/删接口会主动抛错（`app/prompts/file_manager.py:101-112`），设置页的「查看提示词」是只读弹窗。
4. **记录导出没有界面入口**：后端 `GET /api/records/{id}/export` 与前端封装都在，但没有按钮。
5. **LLM「测试连接」没有界面入口**：后端接口与前端封装都在，但没有按钮。
6. **`explain` / `summarize` / `rewrite` 三个 AI 动作没有界面入口**，只有 API 与前端封装。
7. **流式录音的 provider 限制**：仅 `qwen_asr` 与 `doubao_asr`；Qwen 流式在 Windows 上必须依赖远端桥接服务。
8. **`asr_language`、`silence_level`、`selection_toolbar_*` 没有设置界面**（可用但只能改 `data/settings.json`）。
9. **「音频长度上限」是保留配置项**，页面说明中已注明「当前先保留为配置项」，不参与实际处理。
10. **多段录音的已知缺陷**：最后一片上传失败会卡住——`recorder.onstop` 没有 catch，`uploadRealtimeSegment` 只有 `try/finally`，全局 WebSocket 也没有自动重连（项目自身记录于 `AGENTS.md` §5.3）。
11. **LLM provider 未设置超时**：构造客户端时没传 `timeout`，SDK 默认 600 秒（`AGENTS.md` §5.4）。
12. **打包 `--win` 在 nsis 阶段失败**，`release/` 只有 `win-unpacked`（`AGENTS.md` §5.2）——本轮未复现，**待确认**。
13. **剪贴板采集依赖后端可用**：拿不到后端端口时会静默跳过采集（只写日志），此时复制内容不会进历史（`electron/clipboardMonitor/index.js:144-146, 186-189`）。
14. **剪贴板历史单页最多 120 条**，页面没有分页或「加载更多」（`src/components/clipboard/ClipboardPage.vue:168`）。
