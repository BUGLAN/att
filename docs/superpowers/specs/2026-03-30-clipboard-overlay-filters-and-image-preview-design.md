# 剪切板悬浮框筛选与图片预览设计

## 背景

当前统一悬浮层中的剪切板面板只支持搜索和基础列表浏览，存在三个直接影响效率的问题：

1. 无法在悬浮框里快速切到收藏、文本、图片、文件、链接等常用类别。
2. 悬浮框条目缺少低成本收藏动作，用户无法通过右键直接切换收藏状态。
3. 图片条目在悬浮框与 Electron 主界面中都没有可用的显示链路，导致图片历史不可读、不可预览。

本次设计只覆盖现行统一悬浮层路径 `src/components/overlay/ClipboardPanel.vue` 与主界面剪切板页 `src/components/clipboard/ClipboardPage.vue` / `ClipboardCard.vue`，不再扩展已退役的旧悬浮框实现。

## 目标

- 在剪切板悬浮框搜索栏上方提供一排紧凑的快速筛选按钮。
- 让悬浮框条目支持右键立即切换收藏，同时右侧展示收藏图标状态。
- 修复图片条目在悬浮框和主界面中的展示问题，并支持悬停查看清晰缩略图。

## 非目标

- 不引入手动自定义分类或标签系统。
- 不修改主界面剪切板页的右键交互。
- 不重构统一悬浮层整体架构。

## 交互设计

### 悬浮框

- 顶部结构调整为两层：
  - 第一层为紧凑筛选条，按钮包含 `全部 / 收藏 / 文本 / 图片 / 文件 / 链接`。
  - 第二层保留现有搜索输入框。
- 筛选按钮为低高度、细边距的胶囊样式，单选切换。
- `收藏` 视为列表筛选项，而不是额外叠加开关，避免与类别筛选冲突。
- 列表项右侧增加收藏星标图标。
- 在悬浮框中对任意条目执行右键操作时，立即切换该条目的收藏状态，不弹出菜单，不关闭悬浮框。
- 图片条目默认只展示图片名称、更新时间、类型和收藏状态；鼠标悬停条目时，在悬浮框内浮出较大的图片预览卡片。

### 主界面剪切板页

- 主界面卡片修复图片条目展示能力。
- 图片条目默认显示图片名与尺寸摘要，不直接在卡片中铺开图片。
- 鼠标悬停图片卡片时显示大尺寸预览层。
- 主界面不新增右键收藏行为。

## 数据与接口设计

### 列表筛选

不引入新的分类字段，直接复用已有接口参数：

- `全部`：无附加筛选。
- `收藏`：`favorite_only=true`
- `文本 / 图片 / 文件 / 链接`：`item_type=text|image|file|link`

### 图片访问链路

当前图片条目通过 `metadata.image_path` 保存本地文件路径，但前端不能稳定直接使用磁盘路径渲染。为统一主界面和悬浮框的显示链路，新增后端图片读取接口：

- `GET /api/clipboard/items/{item_id}/image`

行为约束：

- 仅在条目存在、类型为图片、且图片文件存在时返回图片文件。
- 其余情况返回 `404`。

前端通过后端地址生成稳定的图片 URL，并用该 URL 作为 `<img>` 的 `src`。

### 图片名称

图片条目优先展示以下名称来源：

1. `metadata.display_name`
2. `metadata.file_name`
3. `title`
4. 默认文案 `未命名图片`

Electron 监听系统剪切板生成图片条目时，同时补充更友好的图片显示名，避免直接把哈希文件名展示给用户。

### 图片复制回系统剪切板

虽然本次需求重点是显示与预览，但在悬浮框中选择图片条目时，如果仍旧把 `image:<hash>` 作为文本写回系统剪切板，会造成行为错误。因此同步补齐 Electron 图片写回能力：

- 渲染层在复制图片条目时，通过 IPC 请求主进程把图片文件重新写回系统剪切板。
- 主进程在写入图片后，使用图片条目的内部标识避免监听器把这次内部写入误判为新的外部采集。

## 组件边界

- `app/clipboard/manager.py`
  - 增加图片文件路径解析能力。
- `app/clipboard/routes.py`
  - 增加图片读取接口。
- `electron/main.js` + `electron/preload.js`
  - 增加图片写回剪切板 IPC。
- `electron/clipboardMonitor/index.js`
  - 为图片内部写入提供去重标识。
- `src/api/client.js`
  - 增加图片 URL 生成方法。
- `src/composables/useElectron.js`
  - 暴露图片剪切板写入能力。
- `src/components/overlay/ClipboardPanel.vue`
  - 增加顶部筛选、右键收藏、收藏图标、图片悬停预览。
- `src/components/clipboard/ClipboardCard.vue`
  - 增加图片卡片的名称与悬停预览展示。
- `src/components/clipboard/ClipboardPage.vue`
  - 同步补齐图片筛选入口与文案。
- `src/utils/clipboardPresentation.js`
  - 收敛筛选映射、类型标签、图片名称、图片 URL 注入等共享展示逻辑。

## 错误处理

- 列表筛选请求失败时，悬浮框保持打开，允许继续搜索和切换筛选。
- 右键收藏失败时，回滚图标状态并提示失败。
- 图片预览失败时，显示“图片不可用”占位，不影响条目复制和列表浏览。
- 图片文件不存在时，后端接口返回 `404`，前端降级为纯文本卡片。

## 测试策略

- Python 单测：
  - 覆盖图片条目路径解析。
  - 覆盖图片类型筛选与统计不回归。
- Node/Electron 侧最小验证：
  - 保持现有统一悬浮层管理器测试通过。
- 手工验证：
  - 悬浮框切换 `全部 / 收藏 / 文本 / 图片 / 文件 / 链接`。
  - 悬浮框右键收藏与取消收藏。
  - 图片条目在主界面与悬浮框中都能显示名称。
  - 悬浮图片预览清晰可见。
  - 选择图片条目后，系统剪切板恢复为图片而不是文本哈希。
