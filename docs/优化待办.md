## 18. 流式每次按下都要重新握手 1.3～2.1 秒（性能，中）

**工作量**：一天（需实测服务端空闲断开时长）。

## 23. 专有名词识别与豆包文件转写速度（体验，低）

- 专有名词识别：TTS 实测「Qwen」→「坤」、「落墨」→「落寞」、「转文字」→「拽文字」，LLM 优化 / 校对都没纠正。热词能解决，但新用户不知道有热词；可考虑内置产品名，或在首次出现英文专名时提示加热词。

## 26. ad-hoc 签名导致每次更新后系统权限可能失效（发布，中，待确认）

**问题**：已安装的 2.7.0 是 ad-hoc 签名（`codesign -dv` 显示 `Signature=adhoc`）。macOS 的麦克风 / 输入监控 / 辅助功能授权按代码签名绑定，ad-hoc 签名每次构建都变，**更新后很可能需要重新授权**（输入监控与辅助功能里旧条目显示为开启但不生效，要删掉重加）。

**建议改法**：先用一次真实更新确认；若属实，用 Developer ID 签名发布（团队 ID 不变授权即可保留），或在更新完成后检测权限并引导用户重新授权。

## 1. 数据面跨域白名单可被绕过（安全，高）

**位置**：`src-tauri/crates/att-server/src/lib.rs` 的 `is_allowed_origin`

**问题**

- 用 `starts_with("http://localhost")` 判断来源，`http://localhost.evil.com` 也会放行（`127.0.0.1`、`tauri.localhost` 同理）。
- 白名单里有 `"null"`。任何网站都能嵌一个 `<iframe sandbox="allow-scripts">`，它发出的请求来源就是 `null`。
- 接口本身没有鉴权。结果是用户用浏览器打开的网页，理论上能读记录和剪贴板历史、改设置、用用户的 LLM 密钥发请求。
- 也没有校验 Host 头，挡不住 DNS rebinding（攻击域名解析到 127.0.0.1 后就是同源）。
- Chrome 新版对公网页面访问本机地址会弹权限提示，能挡掉一部分，但不是所有浏览器都有。

**建议改法**

1. 来源改成解析后精确匹配：协议 + 主机名完全相等（任意端口），去掉 `null`。打包后的来源是 macOS `tauri://localhost`、Windows `http://tauri.localhost`；开发态是 `http://127.0.0.1:8090` / `http://localhost:8090`。
2. 每次启动生成随机 token，沿用 `__ATT_BACKEND_PORT__` 的注入方式交给前端；`api/client.js` 统一带请求头，axum 加一层中间件校验（`/api/health` 可以放行）。
3. 中间件里顺带校验 `Host` 只能是 `127.0.0.1:<端口>` / `localhost:<端口>`。
4. 录音回放用的是 `<audio src>`，带不了请求头：给 `/api/records/{id}/audio` 改用查询参数带 token，或改走 Tauri 的 asset 协议。

**工作量**：半天到一天，主要在前端统一带 token 和回放地址。

## 6. 本地模型加载后常驻不释放（资源，中）

**位置**：`src-tauri/crates/att-core/src/stt/local.rs`（常驻池 `unload`）

**问题**：Whisper large-v3 加载后要占几个 GB 内存，目前只有改设置或手动停止模型服务才会卸载。偶尔用一次本地识别，内存就一直占着。

**建议改法**：常驻池记录最后一次使用时间，后台每分钟检查一次，空闲超过 N 分钟（设置项，默认 15 分钟，0 = 不自动卸载）就 `unload`。下次使用时照常按需加载；首次推理会多几秒，设置页说明这个取舍。录音进行中、文件转写任务未结束时不能卸载。

**工作量**：半天。

## 9. CI 完全不跑 Rust（工程化，中）

**位置**：`.github/workflows/ci.yml`、`src-tauri/crates/att-core/Cargo.toml`

**问题**：托管 runner 上编 CTranslate2 太慢，CI 只跑前端。设置、记录、迁移、LLM 存储这些「旧数据必须能读」的逻辑最需要门禁，现在只靠本机自觉跑测试。

**建议改法**

1. 在 `att-core` 里把 `att-whisper`、`att-qwen` 改成可选依赖，挂在默认开启的 feature（如 `local-engines`）下；`stt/local.rs` 及其引用点按 feature 条件编译，关掉时本地引擎返回「此构建不含本地引擎」。
2. CI 新增 ubuntu job：`cargo fmt --check`、`cargo clippy -p att-core -p att-server -p att-hotkey --no-default-features -- -D warnings`、同样参数的 `cargo test`。`att-app` 依赖 Tauri 系统库，先不进 CI。
3. 先让 clippy 只报不拦（去掉 `-D warnings`），清完存量再收紧。

**工作量**：一天左右，主要在 feature 拆分与条件编译。

## 12. Tauri 未设置 CSP（安全，低）

**位置**：`src-tauri/tauri.conf.json` 的 `app.security.csp`（现为 `null`）

**问题**：目前前端没有 `v-html` / `innerHTML`，没有直接的 XSS 入口，风险不大。但自定义 Tauri 命令不受 capability ACL 限制（能模拟粘贴、按键），一旦将来引入渲染 LLM 输出的 Markdown 之类，缺 CSP 就少了一层兜底。

**建议改法**：设置 CSP，`default-src 'self'`；`connect-src` 放行 `ipc:`、`http://ipc.localhost` 与 `http://127.0.0.1:*`（数据面端口可能随机）；`img-src` / `media-src` 放行数据面地址（剪贴板图片、录音回放）与 `data:` / `blob:`。改完在 macOS 与 Windows 上各过一遍主窗口、悬浮窗、剪贴板悬浮框。

**工作量**：半天，主要在两个平台上回归。

## 顺带记下的后续项

- **旧录音转 FLAC（可选）**：下个版本起新录音存 FLAC（体积约为 WAV 的 53%，用本机 20 个录音实测），旧 WAV 原样保留。本机 `audio/records/` 还有约 288MB WAV，可以做一个「设置 → 诊断」里的手动按钮，逐个转码、校验能解回同样的样本后再替换并改 `audio_path`。属于改写用户数据，不做成自动迁移。
- **FLAC 回放实机确认**：录音回放 `<audio>` 播 FLAC 依赖 WebView 支持（macOS WKWebView、Windows WebView2 理论上都支持），发版前在两个平台各点一次新录音的回放。
- **worktree 共用 Rust 产物目录会串产物**：多个 worktree 共用同一个 `CARGO_TARGET_DIR` 时，目录结构相同的工作区 crate 产物文件名一样，fingerprint 只看相对路径下的源文件时间，可能直接复用别的 worktree 编出来的旧版本（实际遇到过 `unresolved import`）。共用时每次构建前在 `src-tauri/` 下 `find crates src -name '*.rs' -exec touch {} +`。
- **复制来的 target 目录 CMake 缓存指向原路径**：worktree 的 `target/` 若是从主仓库拷来的，`tauri build` / `tauri dev` 用到另一套 feature 组合时 ct2rs / sentencepiece-sys 会因 `CMakeCache.txt` 记录的是原目录而配置失败；删掉对应 `target/debug/build/<crate>-<hash>/out/build` 让它重新配置（要重编 CTranslate2），或回主仓库构建。
