ATT 品牌重塑 · 三个方向

现有视觉资产很统一：金色、宋体粗字、方正印章、「錄 聽 轉 成 敗」五枚状态章。所以我不会另起一套风格，品牌就从「印章 + 一个字」长出来。要定的只有两件事：叫什么，以及品牌章刻哪个字。

LOGO 为什么变了：10-31 的提交 001f308「主窗口按设置页语言重绘」删掉了标题栏的 LogoMark（金底「錄」，即 src/assets/logo-mark.svg），换成文字印章「聲」（glyphs.mjs 的 BRAND_GLYPH）。应用图标和托盘没动，仍是「錄」。结果现在同一个应用有两个标志，logo-mark.svg 也成了没人引用的孤儿文件。
錄应用图标 / 托盘 ≠ 聲标题栏

另一个隐患：「錄」本身就是悬浮窗与托盘的待命状态章。品牌标和状态章用同一个字，用户分不清「这是应用」还是「它现在待命」。新标志最好避开五个状态字。

墨

落墨Luomo推荐

话音落下，即成墨字。
  • 名字讲的是结果，不是功能。「Audio To Text」是一句功能说明；「落墨」是说完那一刻的感觉，和刚做好的墨晕出字是同一个意象，产品体验和名字互相印证。
  • 反色墨底 + 金字，与状态章拉开。状态章都是彩底深字，品牌章是唯一的墨底金字，任何尺寸都不会和「錄」待命章混淆。角上不放红点：Dock / 任务栏会把它读成未读角标。
  • 「墨」不在五个状态字里，五枚状态章一枚都不用动。
  • 代价：图标从金底换成墨底，用户要重新认一次；Dock 里深色图标在深色壁纸上没那么跳。

聲印Shengyin

每一句话，都盖成一枚印。
  • 改动最小的新品牌。沿用现在标题栏的「聲」，图标保留金底深字的造型，只把「錄」换成「聲」，用户几乎无感。

  • 代价：金底深字和「錄」待命章同色同构，小尺寸下仍可能混淆；名字偏「工具感」，记忆点弱于 A。

我的选择：A · 落墨

「印章 + 宋体 + 金」这套语言已经很成熟，缺的是一个讲感觉的名字和一枚只属于品牌的章。「落墨」两样都补上了，和刚做的墨晕出字也是一回事。

落地范围：应用名（tauri.conf.json 的 productName、窗口标题、标题栏）、应用图标 icns / ico / png 用正式字形重新出图（不依赖系统字体）、BRAND_GLYPH、删掉孤儿 logo-mark.svg。托盘和悬浮窗的五枚状态章不动。用户数据目录和 bundle identifier 不改，老用户升级无感。
