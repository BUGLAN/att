# 架构

> 适用版本 **2.1.0**：Tauri 2 + Rust 内核 + Vue 3 前端，单进程原生应用，运行时不依赖 Python / Node。
> 本文只写**当前实现是什么**；还没做完的事、旧代码怎么下线，见 [遗留与下线.md](遗留与下线.md)。

## 1. 三条平面，一个进程

| 平面 | 通道 | 承载什么 | 为什么这么分 |
| --- | --- | --- | --- |
| 控制面 | Tauri command / event | 录音控制、热键、托盘、悬浮窗、剪贴板悬浮框、权限查询、实时增量（`recording:*`） | 低延迟、类型化、随窗口生命周期 |
| 数据面 | 内嵌 axum（仅回环） | 记录 / 设置 / LLM 配置 / 剪贴板 / 文件转写 / health / 音频播放与导出 URL / NDJSON 流 | 前端 `api/client.js` 几乎零改动；播放与下载用 URL 最自然 |
| 音频面 | 进程内（cpal 回调 → Actor mpsc） | 采集、重采样、切段、送识别 | 音频不再穿 WebView，切段与背压都在 Rust 侧 |

数据面端口优先 `17890`，被占用则随机；实际端口会写进 `data/.backend-port`，同时通过 `initialization_script`
注入页面（`window.__ATT_BACKEND_PORT__`），前端首屏无需 invoke 就能拿到。

## 2. 启动链路（`src-tauri/src/lib.rs`）

1. 解析数据目录：`ATT_DATA_DIR` > 开发态仓库 `data/` > 应用数据目录
2. 初始化日志：`data/logs/att-app.log`（每次启动覆盖）
3. 一次性迁移 `att_core::migration::run`（幂等，产出 `migration-report.json`）
4. `CoreState::init`：settings / records / clipboard / llm / prompts
5. 数据面：同步 bind 占端口 → `spawn(serve_on)` → 裸 TCP 自检 `/api/health` → 端口落盘
6. 事件桥：`AppEvent` → 同名 Tauri event
7. 录音 Actor 与全局热键（热键直达 Actor，窗口隐藏时同样可用）
8. `app.manage(AppState)`（含 `shutdown_tx`：它必须活到进程退出，否则数据面会被优雅关闭）
9. 建窗口：`main`（手工创建以便注入端口）、`floating`（预创建隐藏）、`clipboard-panel`（预创建隐藏）
10. 托盘 + 剪贴板后台监控；单实例锁（二次启动唤起主窗口）

## 4. 录音

**状态机**（`src-tauri/src/recording.rs`，单 mpsc 消费者串行决策）：

```text
Idle ──热键/UI──► Connecting ──首帧就绪──► Recording ──松开──► Finalizing ──► Optimizing ──► Idle
                     └──────── 流式握手失败 → 回退批量 ────────┘
```

按住模式的「松开」先进 250ms 松开缓冲（`HOLD_RELEASE_GRACE`，继续收音），缓冲内重新按下就继续本段，到点才进 Finalizing：
按住 ⌘⌥ 时系统偶尔报告 ⌘ 抬起约 200ms 又按回，零容忍会把一句话截成两段。误触判定按真实松开时刻计时，不含缓冲。

**三种模式**（`Mode`，来自设置 `recording_mode`）：

| 模式 | 数据流 | 出字时机 |
| --- | --- | --- |
| `single` 单段 | 全程 PCM → 结束后一次批量识别 | 结束后 |
| `multi` 多段 | `Segmenter` 切段（最短 2.2s / 强制 10s / 收尾门槛 0.8s）→ 每段并发批量识别 → `recording:partial` 拼接 | 边录边出 |
| `streaming` 流式 | 豆包 SAUC 双向流（仅在线引擎） | 边说边出 |

关键保障：并行建连不让开头丢帧；松开时尾包先冲再收尾；启动窗口内的停止请求排队而不是丢弃；多段收尾总上限
120s，单段失败只降级不卡死（旧版「最后一片失败永久卡住」已修）。

采集链路（`att-audio`）：cpal 回调（设备原生采样率与声道）→ 单声道混音 → rtrb 无锁环（约 2s）→ 线性重采样到
16kHz → `i16`；重采样器与 `Segmenter` 都在 `att-core::audio`，回调内不做分配也不加锁。

录音结束后按设置决定是否 `auto_optimize`（优化相位）与 `auto_copy_to_clipboard`（写剪贴板 + 模拟粘贴）。
单段模式在优化期间吞掉新录音；流式模式允许立刻开始下一段（上一段结果转后台，只入库不粘贴）。

## 5. 识别引擎

| 引擎 | 实现 | 说明 |
| --- | --- | --- |
| 豆包（火山） | `stt/doubao.rs` + `stt/sauc.rs`（tokio-tungstenite） | 批量与流式；`asr_provider=doubao` |
| ChatGPT 听写 | `stt/chatgpt.rs`（multipart + 鉴权头） | 批量；流式模式明确提示不支持 |
| 本地 Whisper | `att-whisper`（ct2rs）+ `stt/local.rs` | 复用 `models/faster_whisper` 的 CT2 large-v3，推理前接 Silero VAD |
| 本地 Qwen3-ASR | `att-qwen`（sherpa-onnx，运行期 dlopen） | ONNX int8 0.6B，长音频按静音切点分块；**无流式** |

- 选择规则：显式指定引擎优先；`auto` = 本地优先（与旧 Python 版一致）。本地引擎**懒加载**，首次 5~15 秒。
- 在线引擎同步解析（`Engine::online_from_settings`），本地引擎异步加载（`Engine::resolve`，走 blocking 线程池）。
- 本地模型常驻池按「设置指纹」失效，`/api/model-service/start|stop` 触发预热与释放。
- **热词（个人词表）**：设置 `asr_hotwords`（字符串数组，归一化见 `stt/hotwords.rs`）与引擎无关地保存，走两条路：
  - 识别：目前**只有豆包使用**，随 `DoubaoConfig` 进入每次请求，序列化为 `corpus.context = {"hotwords":[{"word":…}]}`。
    双向流式接口只认 100 tokens，按顺序截取预算内前缀（汉字 1、英文每 4 字母 1 的保守估算，前端 `asrHotwords.mjs` 同规则）；
    有热词时不再发对话上下文（官方没说两者能否合发）；
  - LLM 纠错：`llm::prompt::glossary_block` 生成「用户词表（仅用于纠正识别错误）」块，插在预设正文与安全约定之间
    （AI 优化），或追加在校对 system 末尾（文件校对）；全量词表、不受 token 预算限制，与识别引擎无关。
  - 设置页热词区分两行显示生效情况：「识别 · 引擎」（已生效 / 部分生效 / 不支持）与「LLM 纠错」（随模型与自动优化开关）。
  - 实测（deepseek-flash，8 条原文 A/B，`tests/llm_glossary_ab.rs`）：wait→Vite、磁表热磁→词表热词、Git ignore→.gitignore、
    落寞→落墨 只在带词表时纠正，对照句没有被塞词；`rest 项目` 仍被整理成 REST（REST 本身是合法术语，词表压不过）。
- 识别语言：豆包上 `zh` 与留空（自动）实测无差别（40 条中英混说录音 A/B，`tests/doubao_language_ab.rs`），保持默认 `zh`。
- 实测（RTX 5090 / Windows 11，CPU 推理，22.8s 中文音频）：

| 场景 | 耗时 | 实时率 |
| --- | --- | --- |
| Whisper large-v3，`ruy` 后端（首版） | 220.96s | 9.7× |
| Whisper large-v3，oneDNN + OpenMP | 33.27s | 1.46× |
| Qwen3-ASR-0.6B-int8，2 线程 | 4.7~11.1s | 0.21~0.49× |
| 对照：Python + CUDA float16 | 3.47s | 0.17× |

## 6. LLM 优化

- **服务商目录** `llm/registry.rs`（内置 + `custom` 走 `openai/<ID>`），模型串按档案前缀组装。
- **存储** `llm_v2.json`：档案（含 Fernet 密文密钥）与模型条目，旧格式可直接读。
- **网关** `llm/gateway.rs`：OpenAI 兼容为基座 + Anthropic / Gemini 适配；强制超时与重试（按输入长度分级）；
  流式双看门狗（首字超时、块间空闲）；`reasoning_effort` 映射到上游，不认时自动去掉重试；
  思考 token 占满预算（`output_truncated`）属确定性失败，不重试；错误文案统一过 `redact_secrets`。
- **优化器** `llm/optimizer.rs`：预设模板 → system/user + `<transcript>` 信封（中和伪造标签、超长截断）→
  SSE 流式 → 三层输出清洗 → 落库；同记录互斥、支持取消；失败/取消复位 `transcribed` 并写 `error`。
  `optimize_record_with_preset` 可指定本次预设（None = `default_preset_id`），`optimize_record` 即它的默认预设版。
- **优化选中文本**（快捷键动作 `rewrite_selection`，默认 `⌥A` / `Alt+A`，点按）：不另起流程，复用录音的优化相位。
  Actor 在 Idle 时收到按下 → `desktop::copy_selection`（等修饰键松开 → 模拟 Cmd/Ctrl+C → 按剪贴板换代计数
  `NSPasteboard.changeCount` / `GetClipboardSequenceNumber` 判断有没有真的复制，不比内容）→ 建一条无音频的文本记录
  （`audio_path` 为空、时长 0）→ `begin_optimization(…, OptimizeSource::Selection)`。与录音自动优化的区别只在来源：
  用设置 `rewrite_preset_id` 的预设（空 = 跟随默认预设）、总是流式输回原处（不看「自动复制并粘贴」）、失败且一个字没打出时
  不动选区、取消时若已打出字就把原文放进剪贴板。悬浮窗照常显示「轉」+ 原文，✕ 取消。需要「辅助功能」权限
  （复制与输入都靠它）：macOS 启动时没有它，监听退回只读、不吞键，`⌥A` 会在前台打出 `å` 替换选区，
  运行中补授权也不会变回可拦截——此时 Actor 按 `att_hotkey::listener::suppresses_keys()` 直接提示「授权后重启应用」。
  内置预设 `prompts/Agent 提示词.txt` 是提示词优化器：把草稿 / 口述优化成编程 agent 能直接动手、能自我验证的提示词
  （补目标、范围、调查步骤、验证方式与完成标准，缺的信息写成让 agent 去查的步骤而不是编造）。
- **提示词预设** `prompts.rs` 的 `PromptLibrary`（`CoreState::prompt_library()` 现取现用，无缓存，每次读盘）：
  - 内置：`prompts/*.txt`，id = `preset-<文件名>`（与 Python 版一致），**只读**。打包后资源目录只读、升级会整体覆盖，
    所以不提供「改内置」：内置预设随版本迭代更新，用户自己的提示词用自定义预设，
    不需要「覆盖内置 + 恢复默认」这类覆盖层语义。
  - 自定义：`data/custom_prompts.json`（`{"presets":[{id,name,prompt_template,created_at,updated_at}]}`），
    id = `custom-<uuid>`，改名不改 id，已选用处不受影响。读取宽容（文件缺失 = 没有自定义、缺字段兜底、坏条目跳过）；
    写入在资源锁内「严格读 → 改 → `json_store` 原子写」，文件损坏时拒绝写入（409），避免宽容读回空后覆盖掉用户数据。
    校验：名称去首尾空白、非空、≤ 40 字、不与任何预设重名；正文非空、≤ 20000 字。
  - 列表：内置（按名称）在前、自定义（按创建顺序）在后。HTTP：`GET/POST /api/prompts`、`PUT/DELETE /api/prompts/{id}`
    （内置 → 403）、`PUT /api/prompts/default`。
  - 选用与回退：模板查找链为「本次指定（`rewrite_preset_id`）→ `default_preset_id` → 内置默认（「通用优化」，没有则第一个）
    → 代码内置 `DEFAULT_PROMPT`」。删除自定义预设走 `CoreState::delete_custom_preset`：正被选为默认的回退到内置默认，
    正被「优化选中文本」选用的清空（= 跟随默认），接口回报回退后的值，前端随即重拉设置与列表。

## 7. 存储与迁移

| 路径 | 内容 |
| --- | --- |
| `data/settings.json` | 用户设置（唯一真相源；环境变量只作缺省） |
| `data/records/<id>.json` | 记录（一条一文件，直接平铺在 `records/`） |
| `data/audio/records/` | 记录音频（当前写入位置）；`audio/orphans/` 放迁移期隔离文件；`audio/temp/`、`audio/permanent/` 是旧布局遗留，启动时仍会创建但不再写入 |
| `data/sessions/<id>.json` | 多段会话元数据 |
| `data/clipboard/` | 剪贴板条目 JSON + `images/<sha256>.png` |
| `data/llm_v2.json` | LLM 档案与模型（密钥为 Fernet 密文） |
| `data/.encryption_key` | Fernet 密钥（与旧 Python 密文互认） |
| `prompts/*.txt` | 内置提示词预设（只读；开发态读仓库，安装版读随包资源） |
| `data/custom_prompts.json` | 自定义提示词预设（不存在 = 没有自定义）；`data/prompts/presets.json` 是 Python 版遗留，无代码读取 |
| `data/transcribe_file_cache.json` | 文件转写缓存（LRU + 校对变体） |
| `data/logs/att-app.log` | 运行日志（每次启动覆盖） |
| `data/migration-report.json` | 迁移报告 |

写入一律走 `att_core::storage::json_store`（同目录 tmp + rename），禁止原地截断写。跨进程 `.writer.lock` 已随
单进程架构退役，改由 `tauri-plugin-single-instance` 保证单实例；进程内按资源 `Mutex` 串行化。

## 8. 桌面壳与剪贴板

- **窗口**：`main`（无边框自绘标题栏）、`floating`（录音悬浮条，预创建隐藏）、`clipboard-panel`（剪贴板悬浮框，
  预创建隐藏，快捷键唤起时抢焦点、选中后还焦点再粘贴、尺寸与位置记进设置）。
- **窗口圆角**（`window_shape.rs`）：主窗口无边框，与悬浮窗胶囊同为 10px（`--r-md`）。macOS 透明窗口背景 +
  内容视图图层裁切，全屏时取消；Windows 11 请 DWM 画系统圆角（约 8px，半径不可自定，保留系统阴影）。
  悬浮窗与剪贴板悬浮框本身是透明窗口，圆角由页面 CSS 画。
- **录音悬浮条**（`floating.rs`）：状态只经 `publish` 在一把锁内「读最近状态 → 决定 → 写入并推送」，Actor 相位、
  识别中间结果（`update_partial`，只在仍是「聽」时生效）、收起（`dismiss`，只收已结束的会话）不会互相覆盖。
  按下热键即显示（不等麦克风打开），出现在鼠标所在显示器底部；收起一律先让页面淡出再隐藏窗口
  （系统会留着隐藏前的最后一帧，当场隐藏会让下次显示先闪出旧胶囊）。窗口比胶囊大一圈，页面上报胶囊区域，
  显示期间按光标位置切换 `set_ignore_cursor_events`，透明部分点击穿透。失败原因直接写在胶囊里，点击唤起主窗口。
- **品牌与应用图标**：品牌名「落墨」，标志为墨底金字「墨」（品牌章刻意不用「錄 聽 轉 成 敗」五个状态字）。
  `scripts/generate_brand_icons.py` 从字体矢量（Noto Serif TC，OFL，不入库）逐尺寸栅格化出 `icons/icon.{ico,png,icns}`、
  托盘四态与标题栏用的 `src/assets/brand-mark.svg`：≤48px 用放大字形 + 亚像素对齐的小图版式，ico 含 16/20/24/32/40/48/64/128/256
  （覆盖 Windows 100%~200% 缩放），icns 按 Apple 网格留白。不要用 `tauri icon` 一键缩放覆盖，小尺寸会糊。
- **托盘**：四态图标（待命 = 品牌标「墨」，录音 / 转写 / 断开 = 状态章「聽 轉 斷」，assets 在 `src-tauri/icons/tray/`）。
  Windows 每态出 16/20/24/32/40/48 六档，`tray.rs` 按主屏缩放挑「≥16×缩放」的最小档（缩放变化在下次换态时生效）；
  macOS 用 44px（菜单栏 22pt @2x）。菜单：最近 10 条
  记录（点击=复制并粘贴）+ 设置 + 退出。
- **热键**：macOS `CGEventTap`；Windows `RegisterHotKey`（系统级吞键与冲突检测）+ `WH_KEYBOARD_LL`（key-up）。
  支持多绑定、按住/切换两种触发语义、防粘滞。三个动作：录音、剪贴板悬浮框、优化选中文本；任意两个已启用的绑定撞键时
  设置保存直接拒绝。`settings.json` 的 `hotkeys` 逐条宽容读：认不出的条目（如更新版本新增的动作）只丢那一条。每次触发记日志（来源：修饰键变化 / 按键 / 键态校正，及当时的修饰键）。
  本应用自己的模拟按键（自动输入、粘贴）打 `SYNTHETIC_EVENT_TAG`，监听跳过它们，免得清零的修饰键被当成松开。
- **粘贴与静音**：macOS `CGEvent` + `osascript`（辅助功能授权）；Windows `SendInput` + Core Audio
  `IAudioEndpointVolume`（每次取当前默认输出设备，切换耳机后仍正确）。
- **剪贴板监控**：800ms 轮询（图片优先）；文本规范化去重、图片按 PNG SHA-256 落盘；本应用写入 5 秒内标记跳过，
  避免转写结果反向污染历史。
- **写图片剪贴板**：Windows 必须同时放 `CF_DIB`(24bpp **BI_RGB**) + `CF_DIBV5`(BI_RGB) + `PNG`，并用真实窗口做
  owner —— arboard 默认的 BI_BITFIELDS 写法会让 Skia/Chromium 系（Electron 应用、微信/飞书/WPS、本应用自己的
  WebView2）粘不出图。细节与踩坑写在 `src-tauri/src/clipboard_image.rs` 头部注释里。

## 9. 前端

- **边界**：外部能力只走两层包装 —— HTTP 走 `src/api/client.js`，桌面走 `src/composables/useElectron.js`
  （内部是 `invoke` + Tauri event，导出形状与旧 Electron 版一致，组件层基本零改动）。
- **录音编排**：Rust Actor 是唯一状态机；前端 `useRecorder.js` 是薄客户端，纯逻辑拆在
  `src/composables/recorder/*.mjs`（分段策略、PCM、流协议、悬浮窗文案、托盘状态…），由 `tests/test_recorder_*.mjs` 锁定。
- **页面**：`src/components/{home,transcribe,records,clipboard,settings,layout,floating,clipboardPanel,modals,common}`；
  入口三份：`index.html`（主窗口）、`floating.html`、`clipboard-panel.html`。
- **状态**：Pinia `stores/{app,records,settings,optimizationStream}.js`。
- **提示词预设**：设置页「提示词预设」分「自定义 / 内置」两组（自定义：新增、编辑、删除、设为默认；内置：查看、设为默认），
  弹窗 `modals/PresetEditModal.vue` 按 `settingsStore.presetEditor.mode`（view / edit / create）切换，编辑态点遮罩不关闭以免丢草稿；
  「输出与优化」的两个下拉框（录音默认、优化选中文本）有自定义预设时按「内置 / 自定义」分组。纯逻辑（校验、新建默认名、
  回退、删除确认文案）在 `components/settings/presetLogic.mjs`，由 `tests/test_preset_logic.mjs` 锁定。
- **样式**：`styles/tokens.css`（设计令牌，必须先于组件样式引入）+ 页面级 scoped 样式，图标全内联 SVG。

## 10. 构建、打包与测试

```bash
npm install
npm run tauri:dev        # Vite(8090) + Tauri 壳 + 内嵌数据面
npm run build            # 仅前端构建
npm run tauri:build      # 打包（NSIS / MSI / dmg）
npm run test:rust        # = cd src-tauri && cargo test --workspace
node scripts/run-node-tests.mjs     # 前端纯逻辑用例（必须走这个脚本）
```

> `cargo` 要在 `src-tauri/` 目录内执行：`+crt-static` 配在 `src-tauri/.cargo/config.toml`，
> 只在工作目录位于其下时生效；从仓库根加 `--manifest-path` 跑会 `LNK2038`。

- Windows MSVC 必须 `+crt-static`（`src-tauri/.cargo/config.toml`）：CTranslate2 静态库按 `/MT` 编，否则 `LNK2038`。
- dev 下 CTranslate2 若按 Debug 编会慢约 9 倍，根 `Cargo.toml` 用 `[profile.dev.package.*]` 强制 opt-level=3
  （`ct2rs` / `mel_spec` / `rustfft` / `ndarray` / `tokenizers`），别删。
- 打包资源：`bundle.resources` 把仓库 `prompts/` 装成 `resources/prompts/`；MSI 用简体中文代码页（`zh-CN`）。
- CI：`.github/workflows/ci.yml`（前端 Node 测试 + 构建）、`release.yml`（推 `v*` 标签产 macOS / Windows 安装包并发 Release）。
- 本地引擎的真机测试默认 `#[ignore]`，有模型与音频时手动跑：

```bash
ATT_TEST_WAV=/abs/path/audio.wav cargo test -p att-whisper --test real_model -- --ignored --nocapture
ATT_TEST_WAV=/abs/path/audio.wav cargo test -p att-qwen    --test real_model -- --ignored --nocapture
ATT_TEST_WAV=/abs/path/audio.wav cargo test -p att-core    --test local_engine_wiring -- --ignored --nocapture
```

## 11. 环境变量

| 变量 | 作用 |
| --- | --- |
| `ATT_DATA_DIR` | 数据目录（默认：开发态仓库 `data/`，安装版应用数据目录） |

| `ATT_QWEN_THREADS` | ONNX 线程数（默认 2） |
| `ATT_FFMPEG_DIR` | 显式指定 ffmpeg/ffprobe 所在目录 |
